AI Career Recommendation System (Console-Based)

(Java Console-Based Educational Project)

Project Overview

The AI Career Recommendation System is a Java console-based educational application designed to help users understand suitable career paths based on their interests and self-reported preferences.
The system follows a simple, transparent, rule-based approach and is developed strictly for academic and learning purposes.

The application collects user responses through a text-based quiz and generates career suggestions based on predefined logic. No real machine learning or psychological analysis is used.

Objectives

To demonstrate core Java programming concepts

To implement a menu-driven console application

To apply rule-based decision logic

To use file handling for persistent data storage

To support multi-user interaction

To build a simple, explainable, and viva-ready project

Intended Users

Students exploring career options

Beginners learning Java programming concepts

The system does not provide professional career advice. All outputs are educational demonstrations only.

Key Features

Text-based user interface

Career Assessment Module

User answers a small set of questions
